# ActionBridge v0.5.0

- Send selected Android text directly to your remembered PC clipboard.
- Send files, links and clipboard text from Windows to a paired phone.
- Resume interrupted downloads and verify SHA-256 before saving.
- Windows sent history, drag-and-drop, and cancellation.
- Android received files with Open, plus text/link Copy/Open controls.

Update both apps. No backend update required from v0.4. Keep the phone main screen open to receive. Direct-only remote network limitations remain.
