# ActionBridge

Short description: Send files to your Windows PC. Open, save or print nearby or remotely.

Full description:
ActionBridge brings files, photos, PDFs, text and web links from your Android phone to your Windows PC.

Share from another app, choose your saved PC, and decide what happens next: save the file, open it in its default application, print a PDF or image, copy text, or open a web link.

Automatic local discovery finds your computer. Approve your phone once on the PC, then use the remembered connection. No user account is required. Remote access uses a Cloudflare connection service and encrypted WebRTC, with an optional relay when configured.

Printing controls include printer selection, copies, paper size, orientation, colour, scaling, PDF page range, collated copies and two-sided options on supported printers. Print requests go through your PC's installed Windows drivers. Submitted means Windows accepted the job; check the printer for physical output.

Transfers use an encrypted local connection, integrity checks and resumable uploads. Progress and recent activity help you see what happened. Repeated finish requests are protected against duplicate actions.

Requires the ActionBridge Windows companion on a signed-in, awake Windows x64 PC. Nearby discovery needs local device communication. Remote access needs internet connectivity and a network route between the devices; some networks require the optional relay. Keep the phone screen open during remote transfers. Guest networks may block local discovery. Direct printing supports PDFs and JPG, PNG and BMP images; other file types can be saved or opened in supported desktop applications.

No ads. No developer analytics. No login.
